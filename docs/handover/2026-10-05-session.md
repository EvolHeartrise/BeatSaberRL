## 2. Mirror-exact sim fix: agent in progress
- **Branch** `sim/mirror-exact`. Worktree `../BeatSaberRL-symfix` on the laptop; `/workspace/symfix` (base/ and fix/ builds) on the pod.
- **Handover:** its own note is in `docs/handover/mirror-exact-sim.md` on that branch and in the PR body. It was told to open a draft PR and push immediately.
- **The cause, measured on the CPU Rust sim:** every left/right asymmetry in the env comes from left-first sequential solver passes:
  - the ω-cap pass (`solver.rs` ~1433; CUDA ~3433). This is the main driver: symmetric states pick up about 0.14 rad/s of yaw drift per tick;
  - ground blocks (`collide.rs` ~396 corner order, `solver.rs` ~856 left foot first): ankle-roll tilt from every reset;
  - limit rows (`solver.rs` ~1133);
  - step-11 clamps (`step.rs` ~315) and contact-pair order (`collide.rs` ~297), both minor.

  With every order mirrored, the mirror gap falls to about 1e-13. Body tables, observations, map mirroring, reward, judging and RNG were all verified mirror-exact.
- **The fix:** solve each mirror pair, both feet, and each contact pair with its mirror together from the same pre-state, in both Rust and CUDA.
- **Tests:** a Rust mirror regression test; Python tests that observations mirror exactly and that the mirrors are involutions; CUDA parity on the pod.
- **Merge rule:** merge when CI is green, without `--auto`.

- **30→60 Hz** raises the wrist-reversal R/L ratio for every model. Consistent with the sim-order bias.
- **The advantage filter (top 50% |A|)** amplifies an early lead: a 10% σ gap becomes 14.7% more gradient weight, and 50% becomes 81%. See `train/filt.py`.
- **Mirror operator M** for the 630 observation lanes and 29 action heads: `audit/mirror_ops.py` and `arch/mirror_ops.py`. Verified bit-exact against `set_joints`. On flipped joints, gear ids 1↔2, 3↔4 and 5↔6 swap. The left and right `head_gears` must match.
